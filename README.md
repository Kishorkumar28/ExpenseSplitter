# Expense Splitter App - Frontend

## Overview
The Expense Splitter App frontend is built using **React.js** to provide a seamless and user-friendly experience for managing shared expenses among groups. It allows users to **create groups, add expenses, track debts, and settle payments**.

## Features
✅ **User Authentication** – Secure login & registration using JWT.  
✅ **Dashboard Overview** – Displays app details and user’s groups.  
✅ **Group Management** – Create, view, and invite users to groups.  
✅ **Expense Tracking** – Add, edit, and view all group expenses.  
✅ **Debt Settlement** – View and clear outstanding balances.  
✅ **Responsive UI** – Built with **React, Bootstrap, and Formik validation**.  

## Tech Stack
- **React.js** – Component-based frontend framework.  
- **Redux** – Global state management.  
- **React Router DOM** – Handles navigation & routing.  
- **Formik & Yup** – Form validation.  
- **Bootstrap** – Minimal UI styling.
